# Instapro

## Описание проекта

Instapro — учебное веб-приложение, позволяющее пользователям просматривать и публиковать фотографии. Проект взаимодействует с REST API и реализует основные функции социальной сети.

## Реализованный функционал

- Просмотр списка постов, полученных с сервера.
- Регистрация и авторизация пользователей.
- Сохранение авторизации в LocalStorage.
- Добавление новых постов с описанием и загрузкой изображения.
- Просмотр постов конкретного пользователя.
- Постановка и снятие лайков.
- Обработка ошибок при работе с API.
- Отображение состояния загрузки при выполнении запросов.

## Используемые технологии

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- REST API
- Fetch API

## Структура проекта

- `index.js` — точка входа приложения и маршрутизация.
- `api.js` — взаимодействие с API.
- `components/` — компоненты приложения.
- `helpers.js` — вспомогательные функции.
- `routes.js` — маршруты приложения.

## Как запустить проект

1. Склонировать репозиторий.
2. Открыть проект в Visual Studio Code.
3. Запустить локальный сервер (например, Live Server).
4. Открыть приложение в браузере.
